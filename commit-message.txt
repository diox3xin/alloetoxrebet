feat: централизованная система уведомлений с понятными описаниями ошибок

Добавлена новая система обработки ошибок и уведомлений для всех приложений Astral Phone.

Изменения:

* apps/notifications.js - новый модуль с централизованными уведомлениями
  - handleApiError() - обработка ошибок API с детальным описанием
  - handleGenerationError() - ошибки генерации контента
  - handleImageGenerationError() - ошибки генерации изображений
  - describeHttpError() - понятные описания HTTP статусов (401/429/500/etc)
  - describeFetchError() - обработка сетевых ошибок (таймаут/CORS/SSL)

* Интегрировано во все приложения:
  - apps/prompt-llm.js - HTTP ошибки с детальным описанием
  - apps/messages.js - ошибки генерации ответов персонажей
  - apps/gallery.js - ошибки генерации изображений
  - apps/creator.js - ошибки генерации контента и изображений
  - apps/notes.js - ошибки генерации заметок
  - apps/spicy.js - ошибки генерации превью
  - apps/social.js - ошибки генерации постов

* Удалено:
  - Дублирующие методы _toast() из всех приложений
  - Промежуточные информационные сообщения ("Генерирую…")

* Документация:
  - MESSAGES_SYSTEM.md - полное описание архитектуры системы сообщений
  - CHANGELOG_notifications.md - детали изменений и примеры использования

Преимущества:
- Понятные сообщения вместо технических HTTP статусов
- Различение типов ошибок (неверный ключ vs лимит vs ошибка сервера)
- Единообразие во всех приложениях
- Автоматическое логирование в консоль для отладки
- Централизованное место для доработок
