# 🌌 Astral Phone — расширение для SillyTavern

**Реалистичный телефон персонажа** с чатами, галереей, Spicy Hub и Creator Studio.  
Модель генерирует события — расширение обрабатывает их и показывает результат в стеклянном интерфейсе.

---

## Возможности

### 📱 **Messages** — переписки с персонажем
- Список тредов, отсортированных по последнему сообщению
- При открытии треда — полная история переписки
- Модель может отправить SMS через `<phone type="message">`

### 📷 **Gallery** — фотоальбом
- Персонаж делает селфи, фотографирует окружение, людей, места
- Модель отправляет событие с описанием — расширение генерирует картинку через Haruspics
- Промпт отображается как оверлей снизу
- Можно генерировать все фото пачкой через кнопку «Создать все фото»

### 🔥 **Spicy Hub** — анонимная лента 18+
- Персонаж публикует ролики (thumbnails)
- Фильтры: Все, Новое, Тренды, Смотреть позже
- Просмотры, лайки, длительность, теги
- Thumbnails генерируются через Haruspics (nsfw: true)

### 💎 **Creator Studio** — платформа для контента
- **Профиль**: подписчики, посты, доход
- **Лента**: опубликованные посты (картинка + подпись)
- **Статы**: заработок, средние лайки, лучший пост
- **Фаны**: донаты и новые подписчики
- Модель может публиковать контент, получать донаты, набирать подписчиков

## Установка

### 1. Скопировать расширение в ST
```bash
# Скачай репозиторий и скопируй в папку расширений
data/<user>/extensions/st-phone-astral/
```

Или установи через **Install Extension** в SillyTavern, указав URL репозитория.

### 2. Включить в ST
1. Открой **Extensions** → **Install Extension**
2. Найди `st-phone-astral` в списке
3. Включи галочку

### 3. Настроить Haruspics (опционально)
Для генерации изображений понадобится расширение [Haruspics Fusion](https://github.com/aelynna/SillyTavern-Haruspics-Fusion).  
Если оно не установлено, кнопки «Создать фото» будут заблокированы.

## Как использовать

### В промпте персонажа добавь:
```
Ты можешь использовать свой телефон для:
- Отправки SMS: <phone type="message" character="Лиза Воронова" description="Не надо. Просто говори со мной.">
- Публикации фото в галерею: <phone type="gallery" description="селфи в тёмной ванной, мокрые волосы, свет от телефона снизу">
- Публикации роликов в Spicy Hub: <phone type="spicy" description="night routine" metadata='{"tags":["домашнее","тёмная"]}'>
- Публикации контента в Creator Studio: <phone type="creator" event="content_posted" description="новый сет в ванной — прозрачное кружево, мокрые волосы, свет от телефона">
- Получения доната: <phone type="creator" event="donation_received" metadata='{"fan":"Макс","amount":50}'>
- Новых подписчиков: <phone type="creator" event="subscriber_joined" metadata='{"fan":"Аноним","count":3}'>
```

### Открыть телефон
Кликни на кнопку **📱 Phone** в шапке чата (появляется автоматически после инициализации расширения).

### Генерация изображений
- Галерея и Creator Studio автоматически создают плейсхолдеры с кнопкой «Создать фото»
- Haruspics генерирует картинку по промпту
- Результат сохраняется в `chat_metadata`, так что все данные привязаны к текущему чату

## Дизайн

**Astral** = тёмный космический стиль с эффектом стекла, звёздами и градиентами.

- Цветовая палитра: `#0D0B10` (фон), `#D99AB5` (акцент), `#E5AFC5` (светлый акцент)
- Шрифты: `Unbounded` (заголовки), `Jost` (текст)
- SVG-иконки вместо эмодзи
- Glassmorphism: `backdrop-filter: blur(12px)`, радиальные градиенты, тонкие обводки

Если стиль не твой — замени `style.css` на любой другой. Логика в `apps/*.js` полностью отвязана от оформления.
