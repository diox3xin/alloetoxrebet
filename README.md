# Astral Phone — SillyTavern Extension

Полнофункциональный смартфон-интерфейс для персонажей: чаты, фотоальбом, контент-платформы. Все события генерируются моделью через function calling или скрытые теги.

## Возможности

- 📱 **Корпус телефона** — стеклянная тёмная UI с розово-лиловой палитрой
- 💬 **Сообщения** — SMS/чаты с персонажами
- 📷 **Галерея** — фотоальбом с генерацией картинок по событиям
- 🔞 **Spicy Hub** — анонимная лента NSFW-контента с превью
- 💎 **Creator Studio** — монетизация контента (подписчики, донаты, аналитика)

## Требования

- **SillyTavern** ≥ 1.13.0
- **Haruspics Fusion** или аналог для генерации картинок (опционально)

## Установка

1. Открой SillyTavern → Extensions → Install Extension
2. Вставь URL репозитория:
   ```
   https://github.com/diox3xin/alloetoxrebet
   ```
3. Нажми **Install**
4. Перезагрузи страницу

## Использование

### Открытие телефона
Справа в шапке чата появится иконка 📱 — кликни, чтобы открыть телефон.

### Как модель пишет события

#### Через function calling (Claude, GPT-4, Gemini)
Модель автоматически вызывает:
```javascript
phone_event({
  type: 'photo_taken',        // тип: photo_taken, message_received, content_posted
  character: 'Лиза Воронова', // кто
  description: 'селфи в ванной комнате', // описание для генерации
  timestamp: 1699294820000    // опционально
})
```

#### Fallback (скрытые теги)
Если модель не поддерживает tools, добавь в промпт:
```
Когда персонаж делает фото, отправляет сообщение или выкладывает пост — оберни это в тег:
<phone-event type="photo_taken" character="Имя" description="краткое описание для картинки" />

Тег стирается из видимого сообщения, но событие попадает в телефон.
```

### Генерация картинок
Расширка интегрируется с **Haruspics Fusion**. Если haruspics установлен и настроен, кнопки "📸 Создать фото" и "➕ Опубликовать" автоматически генерируют изображения через активный провайдер (Naistera / NovelAI / OpenAI / другие).
