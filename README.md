# 🌌 Astral Phone — расширение для SillyTavern

**Реалистичный телефон персонажа** с чатами, галереей, Spicy Hub и Creator Studio.  
Модель генерирует события — расширение обрабатывает их и показывает результат в стеклянном интерфейсе.

---

## Возможности

### 📱 **Messages** — переписки с персонажем
- Список тредов, отсортированных по последнему сообщению
- При открытии треда — полная история переписки
- Ответить персонажу можно прямо из телефона — модель увидит это в промпте
- Модель присылает сообщения через `phone_event` (или тег `<phone-event>`)
- Долгое нажатие / правый клик по сообщению — удалить

### 📝 **Notes** — приватный дневник персонажа
- Четыре типа записей: дневник, план, секрет, заметка
- Генерация моделью от первого лица, с привязкой к реальным событиям сцены
- Каждая заметка — про игрока: что он значит персонажу, что тот скрывает
- Последние записи видны модели в промпте — персонаж помнит, что сам записал

### 🐦 **Social** — публичная лента
- Посты с аватаром, ником, временем; лайки, репосты, комментарии
- Свой профиль: имя, ник, «о себе»
- Кнопка «Пост персонажа» — выбрать, кто пишет (по сцене) или рандом
- Лента заполняется постами и заметками ещё до начала сюжета

### 📷 **Gallery** — фотоальбом
- Персонаж делает селфи, фотографирует окружение, людей, места
- Модель отправляет событие с описанием — расширение генерирует картинку через Haruspics
- Промпт спрятан под «Промпт ▾» — можно раскрыть и отредактировать
- Фото можно перегенерировать и удалить

### 🔥 **Spicy Hub** — анонимная лента 18+
- Персонаж публикует ролики (thumbnails)
- Фильтры: Все, Новое, Тренды, Смотреть позже
- Просмотры, лайки, длительность, теги
- Thumbnails генерируются через Haruspics (nsfw: true)

### 💎 **Creator Studio** — платформа для контента
- **Профиль**: подписчики, посты, доход
- **Лента**: опубликованные посты (картинка + подпись)
- **Статы**: заработок, средние лайки, лучший пост
- **Фаны**: донаты и новые подписчики
- Модель может публиковать контент, получать донаты, набирать подписчиков

### ⚙️ **Settings** — настройки телефона
- Профиль персоны: имя, ник, аватар, «о себе»
- Справочник внешности: имена и описания внешности подставляются в промпт
- Профили API для генерации промптов, стиль из Haruspics подхватывается автоматически

## Установка

### 1. Скопировать расширение в ST
```bash
# Скачай репозиторий и скопируй в папку расширений
data/<user>/extensions/st-phone-astral/
```

Или установи через **Install Extension** в SillyTavern, указав URL репозитория.

### 2. Включить в ST
1. Открой **Extensions** → **Install Extension**
2. Найди `st-phone-astral` в списке
3. Включи галочку

### 3. Настроить Haruspics (опционально)
Для генерации изображений понадобится расширение [Haruspics Fusion](https://github.com/aelynna/SillyTavern-Haruspics-Fusion).  
Если оно не установлено, кнопки «Создать фото» будут заблокированы.

## Как использовать

### Как модель сообщает телефону о событиях

Расширение само подмешивает в промпт блок `[Astral Phone — интерфейс телефона персонажа]`, поэтому вручную ничего добавлять не нужно. Модель сообщает о событии одним из двух способов:

1. **Вызов инструмента `phone_event`** — основной путь. Работает, если в ST включён **Function Calling** (Настройки API → Function Calling). Если выключен, инструмент не уходит провайдеру, и модель переключится на второй путь.
2. **Тег в тексте ответа** — запасной путь, который работает всегда. Тег вырезается из сообщения, поэтому в чате его не видно:

```html
<phone-event type="message_received" character="Лиза Воронова" description="Не надо. Просто говори со мной." />
```

Атрибуты: `type`, `character`, `description`, плюс `title` / `kind` / `amount` / `count` для заметок, постов и донатов.

Типы событий: `message_received`, `photo_taken`, `spicy_posted`, `content_posted`, `note_written`, `social_post`, `donation_received`, `subscriber_joined`.

> После обновления расширения сделайте полную перезагрузку страницы (**Ctrl+F5**) — иначе браузер отдаст старый кэшированный скрипт и правки не применятся.

> Если в консоли браузера (F12) нет строки `[Astral Phone] ready` — расширение не загрузилось. Проверьте, что в `manifest.json` поле `js` указывает на `astral-phone.js`, а в самом файле есть `export { onActivate }`: ST грузит расширения как ES-модуль и активирует их через этот экспорт.

### Открыть телефон
Кнопка **📱** в правом нижнем углу (плавающая). На мобильном свайп вниз по шапке или свайп справа закрывает телефон.

### Генерация изображений
- Галерея и Creator Studio создают плейсхолдеры с кнопкой «Создать фото»
- Haruspics генерирует картинку по промпту
- Результат сохраняется в `chat_metadata`, так что все данные привязаны к текущему чату

## Разработка

Исходники лежат в `apps/` и `index.js`. В SillyTavern грузится собранный `astral-phone.js` — его нужно пересобирать после правок.

```bash
npm install
npm run build     # esbuild index.js → astral-phone.js (ESM, как грузит ST)
npm test          # 17 тестов парсера + 13 тестов собранного бандла
npm run report    # собрать out/report.html — проверка в браузере
```

Бандл собирается именно в формате ESM: ST загружает расширения как `<script type="module">` и вызывает экспортированную функцию из `manifest.hooks.activate`. Без экспорта `onActivate` расширение молча не активируется.

Тесты (`test/`) не требуют SillyTavern: `bundle-smoke.test.mjs` поднимает стаб и грузит настоящий `astral-phone.js`.

## Публикация изменений

Скрипт `ОПУБЛИКОВАТЬ.bat` (двойной клик) делает всё сам: находит токен — сначала через GitHub CLI, затем в Credential Manager, и только если не нашлось — спрашивает в скрытом окне (ввод не появляется на экране и не попадает в чат). Потом записывает токен в `.git-credentials-local` (файл в `.gitignore`, в репозиторий не уедет), отправляет `main` и сверяет, что сервер и локальная копия совпадают.

Если у вас есть `gh` и вы делали `gh auth login` — токен подхватится сам, ничего вводить не придётся.

## Дизайн

**Astral** = тёмный космический стиль с эффектом стекла, звёздами и градиентами.

- Цветовая палитра: `#0D0B10` (фон), `#D99AB5` (акцент), `#E5AFC5` (светлый акцент)
- Шрифты: `Unbounded` (заголовки), `Jost` (текст)
- SVG-иконки вместо эмодзи
- Glassmorphism: `backdrop-filter: blur(12px)`, радиальные градиенты, тонкие обводки

Если стиль не твой — замени `style.css` на любой другой. Логика в `apps/*.js` полностью отвязана от оформления.
