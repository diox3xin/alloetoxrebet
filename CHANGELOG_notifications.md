# Astral Phone — Обработка ошибок и система уведомлений

## Изменения от 15.11.2026

### Добавлено

**Новый модуль `apps/notifications.js`:**
- Централизованная система уведомлений для всех приложений
- Понятные описания HTTP и сетевых ошибок
- Специализированные обработчики для разных типов ошибок

**Основные функции:**
```javascript
// Базовые уведомления
success(message)
info(message)
warn(message)
error(message)

// Обработка ошибок
handleApiError(error, {silent?, prefix?})
handleGenerationError(error, context, {silent?})
handleImageGenerationError(error, {silent?})

// Описание ошибок
describeHttpError(status, body)
describeFetchError(error)
```

### Примеры понятных сообщений

**Было:**
```
HTTP 401: {"error":"invalid_api_key"}
```

**Стало:**
```
Неверный API ключ (401). Проверьте ключ в настройках.
```

**Было:**
```
Error: HTTP 429: Too Many Requests
```

**Стало:**
```
Превышен лимит запросов (429). Подождите немного.
```

**Было:**
```
Error: Failed to fetch
```

**Стало:**
```
Ошибка сети. Проверьте подключение к интернету.
```

### Типы ошибок и их обработка

| Статус | Описание |
|--------|----------|
| 400 | Неверный запрос (проверьте параметры) |
| 401 | Неверный API ключ (проверьте настройки) |
| 403 | Доступ запрещён (проверьте права ключа) |
| 404 | Endpoint не найден (проверьте адрес) |
| 429 | Превышен лимит запросов (подождите) |
| 500 | Ошибка сервера (попробуйте позже) |
| 502 | Сервис недоступен (попробуйте позже) |
| 503 | Сервис перегружен (попробуйте позже) |

**Сетевые ошибки:**
- AbortError → Таймаут подключения
- Failed to fetch → Ошибка сети
- CORS → Провайдер блокирует запросы
- SSL → Ошибка сертификата

### Специальные обработчики

**Ошибки генерации изображений:**
- Haruspics не установлен
- Провайдер не найден
- Не задан API ключ
- Ошибки API провайдера

**Ошибки генерации текста:**
- Автоматическое определение контекста (сообщение/пост/заметка)
- Детальное описание причины
- Консоль для отладки

## Тестирование

### Проверка ошибок подключения

1. Неверный endpoint:
   ```
   Endpoint не найден (404). Проверьте адрес в настройках.
   ```

2. Неверный ключ:
   ```
   Неверный API ключ (401). Проверьте ключ в настройках.
   ```

3. Rate limit:
   ```
   Превышен лимит запросов (429). Подождите немного.
   ```

4. Таймаут:
   ```
   Таймаут подключения. Проверьте сеть и адрес API.
   ```

### Проверка генерации

1. Ответ персонажа в Messages:
   - При успехе: нет уведомления (сообщение просто появляется)
   - При ошибке: "Не удалось сгенерировать ответ персонажа: [описание]"

2. Фото в Gallery:
   - При успехе: "Готово"
   - При ошибке: "Не удалось создать изображение: [описание]"

3. Заметка в Notes:
   - При успехе: "Запись добавлена" или "Добавлено записей: N"
   - При ошибке: "Не удалось сгенерировать заметку: [описание]"

## Миграция

### Как обновить старый код

**Было:**
```javascript
try {
    const result = await something();
    this._toast('Готово', 'success');
} catch (err) {
    console.error('[App] failed:', err);
    this._toast(`Ошибка: ${err.message}`, 'error');
}
```

**Стало:**
```javascript
import { success, handleApiError } from './notifications.js';

try {
    const result = await something();
    success('Готово');
} catch (err) {
    handleApiError(err);
}
```

### Правило выбора обработчика

- **API/сеть** → `handleApiError(err)`
- **Генерация текста** → `handleGenerationError(err, 'что')`
- **Генерация изображений** → `handleImageGenerationError(err)`
- **Простое уведомление** → `success()`, `error()`, `warn()`, `info()`

## Отладка

### Логи в консоли
Все уведомления дублируются в консоль с префиксом `[Astral Phone] [TYPE]`:
```
[Astral Phone] [ERROR] Неверный API ключ (401). Проверьте ключ в настройках.
[Astral Phone] [SUCCESS] Пост опубликован
```

### Структура ошибок
При обработке ошибок HTTP добавляются поля:
```javascript
error.status = 401;
error.body = '{"error":"invalid_api_key"}';
```

Это позволяет более точно определить причину и дать понятное описание.
