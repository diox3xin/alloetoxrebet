# Тестирование системы уведомлений

## Быстрая проверка

### 1. Установка расширения
```bash
# В SillyTavern: Extensions → Install Extension
# URL: https://github.com/diox3xin/alloetoxrebet
```

### 2. Тестовые сценарии

#### A. Проверка ошибок API (Настройки → Astral Phone → API)

**Неверный endpoint:**
1. Endpoint: `https://fake-api.example.com/v1`
2. API ключ: `test-key`
3. Нажать "Подключиться"
4. **Ожидается:** "Endpoint не найден (404)" или "Ошибка сети"

**Неверный ключ (если есть рабочий API):**
1. Endpoint: ваш рабочий
2. API ключ: `sk-wrongkey123`
3. Нажать "Подключиться"
4. **Ожидается:** "Неверный API ключ (401). Проверьте ключ в настройках."

**Rate limit (если провайдер поддерживает):**
1. Быстро создать много сообщений/заметок/фото
2. **Ожидается:** "Превышен лимит запросов (429). Подождите немного."

#### B. Проверка генерации контента

**Messages — ответ персонажа:**
1. Открыть телефон → Messages
2. Открыть любую переписку
3. Нажать кнопку "ответить от персонажа" (иконка сообщения справа)
4. **При успехе:** новое сообщение появляется, без уведомления
5. **При ошибке:** "Не удалось сгенерировать ответ персонажа: [описание]"

**Notes — генерация заметок:**
1. Открыть телефон → Notes
2. Нажать кнопку "AI" в правом верхнем углу
3. Выбрать тип (Дневник/План/Секрет)
4. **При успехе:** "Запись добавлена" или "Добавлено записей: N"
5. **При ошибке:** "Не удалось сгенерировать заметку: [описание]"

**Gallery — генерация фото:**
1. Открыть телефон → Gallery
2. Нажать на любое фото без картинки
3. **При успехе:** "Готово"
4. **При ошибке (нет Haruspics):** "Не удалось создать изображение: Haruspics не установлен..."
5. **При ошибке API:** детальное описание проблемы

**Social — генерация постов:**
1. Открыть телефон → Social
2. Нажать кнопку "AI post" внизу
3. **При успехе:** "[Имя]: пост опубликован"
4. **При ошибке:** "Не удалось сгенерировать пост: [описание]"

#### C. Проверка успешных операций

**Удаление:**
1. Messages: долгое нажатие на сообщение → удалить
   - **Ожидается:** "Сообщение удалено"
2. Gallery: нажать на фото → "Delete"
   - **Ожидается:** "Photo deleted"
3. Notes: нажать на заметку → корзина
   - **Ожидается:** "Запись удалена"

**Сохранение:**
1. Gallery: открыть камеру → настройки → сохранить
   - **Ожидается:** "Настройки сохранены"
2. Social: редактировать профиль → сохранить
   - **Ожидается:** "Профиль сохранён"

## Что проверять в консоли

### 1. Формат логов
```javascript
[Astral Phone] [ERROR] Неверный API ключ (401). Проверьте ключ в настройках.
[Astral Phone] [SUCCESS] Пост опубликован
[Astral Phone] [INFO] Операция выполнена
```

### 2. Структура ошибок HTTP
```javascript
// При fetch ошибке должно быть:
error.status = 401
error.body = '{"error":"invalid_api_key"}'
error.message = "Неверный API ключ (401). Проверьте ключ в настройках."
```

### 3. Отсутствие старых сообщений
❌ Не должно быть:
- `HTTP 401: ...`
- `Error: ...`
- Сырые JSON объекты ошибок

✅ Должны быть:
- Понятные описания на русском
- Контекст ("проверьте ключ", "подождите немного")

## Известные проблемы

### Если уведомления не показываются
1. Проверьте консоль — логи должны быть там
2. Убедитесь, что toastr доступен: `window.toastr` в консоли
3. Проверьте, что файлы пересобраны: размер `astral-phone.js` должен быть ~370KB

### Если ошибки показываются на английском
Это значит, что catch блок находится выше в стеке и перехватывает ошибку до того, как она попадёт в обработчик. Нужно искать промежуточные try/catch.

### Если дублируются уведомления
Проверьте, что старые методы `_toast()` удалены из всех приложений:
```bash
grep -n "_toast(" apps/*.js
# Должно быть пусто
```

## Отладочные команды

```bash
cd C:/tmp/st-phone-astral
grep "import.*notifications" apps/*.js
```

### Подсчёт использований
```bash
grep -c "handleApiError\|handleGenerationError\|handleImageGenerationError" apps/*.js
```

### Проверка сборки
```bash
npx esbuild index.js --bundle --format=iife --outfile=astral-phone.js --platform=browser --keep-names --minify=false
# Должно быть: astral-phone.js  370.3kb, Done in ~10-20ms
```
